NEWCASTLE TEAM — CONFIGURACIÓN RÁPIDA
=====================================

1. SUPABASE
-----------
Crea un proyecto y ejecuta:

supabase/schema.sql

Copia SUPABASE_URL y SUPABASE_SERVICE_ROLE_KEY.

2. DISCORD
----------
Crea una aplicación en Discord Developer Portal.
Copia:

DISCORD_BOT_TOKEN
DISCORD_PUBLIC_KEY
DISCORD_APPLICATION_ID
DISCORD_GUILD_ID

Invita el bot con bot + applications.commands.

3. GROQ
-------
Crea una clave y guárdala como:

GROQ_API_KEY

4. VERCEL
---------
En Settings > Environment Variables agrega todo lo que aparece en .env.example.
No pongas ninguna clave en app.js o platform.js.

5. INTERACTIONS URL
-------------------
En Discord coloca:

https://TU-DOMINIO.vercel.app/api/discord/interactions

6. COMANDOS
-----------
En una computadora con Node.js:

npm install
npm run register:discord

7. USO
------
Jugador:
/avisos activar nickname:SuNombre

DT:
Abre la sección Oficiales de la página, escribe ADMIN_SECRET, crea el partido
y selecciona convocados.

8. PRUEBA LOCAL
---------------
Copia .env.example como .env.local y ejecuta:

npm run local

Abre:
http://localhost:3000

9. REC INCLUIDA
---------------
La página tiene un botón “Probar rec incluida”.
También puedes ejecutar:

npm run test:replay

IMPORTANTE
----------
El analizador actual extrae datos básicos del HBR2. No calcula todavía mapas
de calor, posesión o pases completos cuadro por cuadro.


10. CORRECCIÓN PARA VERCEL HOBBY
--------------------------------
El cron fue cambiado de cada hora a una vez al día:

0 0 * * *

Esto permite desplegar el proyecto en el plan gratuito de Vercel.
La ejecución será aproximadamente a las 00:00 UTC, cerca de las 6:00 PM
en Monterrey.

Para avisos cada hora necesitas Vercel Pro o un programador externo que
llame a /api/cron/reminders usando CRON_SECRET.

El archivo vercel-pro-hourly.example.json conserva la configuración para Pro.
